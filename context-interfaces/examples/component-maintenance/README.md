# Component maintenance

This Context Interface describes a source-linked maintenance reference for
reusable components and the stories that demonstrate them. It comes from an
approved Interface used to build an actual Ready Graph.

The reference contains component, story, source-reference and maintenance-note
nodes, with relationships connecting demonstrations, evidence and observations.
Its required entrypoint is `maintenance-reference.md`; focused nodes live under
`reference/`, one file per node. Source selection and Build instructions belong
to each Graph's approved Build Plan.
